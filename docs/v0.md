# v0 application rail

## Product decisions

- `All` means product-visible sessions. Archived sessions are intentionally excluded.
- The 56px AppFrame rail is retained and treated as a candidate final posture, not a temporary shim.
- The workspace/session tree is not rendered in the rail. Session navigation moves to a transient switcher.
- The rail owns global session navigation/attention entry points, not archive browsing.
- Vanilla DSH's Big Fat Whale returns as a passive brand landmark at the head of the tree-less rail.
- The rail uses vanilla DSH's 36x36 control-seat rhythm; the Whale is 24px wide and Material search/add/activity glyphs are optically sized at 22/24/20px.
- Rice-owned hierarchy uses semantic tonal regions, spacing, shape, and elevation instead of a rail-length separator, panel outline, and header-length divider.
- Hover, pressed, keyboard-active, current, and focus-visible remain distinct states.
- No spec-level keyboard chords are assigned in v0. Durable command ids are separate from host/platform keymaps.

## Upstream seams

v0 deliberately keeps upstream `AppFrame`. Current public source at
`47f943859bef60e4160492346772ded9b24f765a` establishes:

- `sidebar` is a whole-surface single slot;
- `sidebar = 0` resolves to the fixed 56px control rail; the sidebar never concedes to 0px;
- the vanilla collapsed rail uses 36x36 control seats in the 56px track;
- `FishLogo` is a root export of `@deepseek-ai/dsh-client-ui-primitives`;
- DSH Web seeds `@deepseek-ai/dsh-client-ui-primitives` into its frozen public platform module table;
- upstream `FishLogo` preserves the Figma-derived 23.16x17.04 geometry and uses `currentColor`;
- `ctx.sessions.list` is the metadata authority for visible session rows;
- `ctx.workspaces.list.archivedSessionIds` is the archive authority;
- `ctx.sessions.search()` is optional message-content search and is not the canonical corpus;
- DSH theme exposes semantic brand, surface, selector, navigation-state, mask, label, and elevation variables.

The browser artifact follows the rc.6-compatible namespace-loader shape already
physically dogfooded by `dsh-matugen`: named namespace exports, no default
export, and one `window.__ModuleLoader__.load(...)` artifact.

## Big Fat Whale semantics

`dsh-rice` imports `FishLogo` from the public DSH platform module. It does not
fork the logo path or add a third-party brand asset.

The mark rides `--dsw-alias-brand-primary`, so stock DSH supplies its normal
brand ink and optional semantic providers can recolor the same alias. No
`dsh-matugen` import, detection, RPC, or package dependency is introduced.

The landmark is passive and labelled `DeepSeek`. Vanilla's logo-toggle behavior
depends on a meaningful expanded sidebar. Rice deliberately has no persistent
workspace/session tree, so a toggle would expose no valid product state.
Sessions and New Session remain separate adjacent controls.

## Session projection

The switcher derives rows from `ctx.sessions.list` + `ctx.workspaces.list` only.
It mirrors upstream top-level navigation semantics:

- archived sessions are excluded;
- subagent-origin children are excluded from the top-level switcher;
- blank sessions are hidden except for the selected blank session;
- workspace membership/order comes from `workspace.sessionIds`;
- loose sessions trail under `Ungrouped` by recency.

Search is an in-memory fuzzy projection over already-visible metadata
(title/workspace/cwd/agent preset). It does not maintain a second session index
and does not require the opt-in full-text provider.

Workspace paths are shown once at group level where possible rather than
repeated under every row. A row uses agent preset as its preferred secondary
metadata; a distinct cwd remains available when it adds information.

## Sessions and Activity

The transient surface has two explicit modes:

- **Sessions** shows the complete product-visible projection and can start a New Session.
- **Activity** applies `overviewGroups()` to the same projection and shows current/running/completed/pending-interaction rows.

Activity remains an Activity projection while searching. Entering a query
cannot silently switch it back to the full Sessions corpus.

The current Session is indicated by the status column, a semantic accent-tonal
row, an inset brand marker, and `aria-current="page"`. The older duplicate
leading-dot marker is not rendered.

## Soft-region grammar

The rail uses `--dsw-specific-sidebar-fill` as its region boundary and drops its
rice-owned full-height right border.

The transient panel uses `--dsw-specific-menu` plus `--dsw-shadow-lv2`, without
a decorative panel border. The mode/search/New Session controls sit in an inset
`--dsw-specific-selector` region rather than above a full-width bottom divider.

Session states use DSH's existing semantic roles:

```text
hover            sidebar-nav-item-hover
keyboard-active  sidebar-nav-item-active
current          sidebar-nav-item-active-accent + brand inset
pressed          interactive-bg-active
focus-visible    two-pixel brand-primary ring
```

The badge uses brand-primary/on-primary-compatible semantic aliases. The
backdrop uses the DSH mask alias. Rice source defines no fixed color and never
overrides `--dsw-static-*`.

## Typography and pacing

Only rice-owned overlay text changes in this slice:

- mode label: compact label leading and letter spacing;
- search: 15/22 pacing inside the inset control region;
- Workspace label/path: separated hierarchy with a bounded path measure;
- Session title/metadata/status: 14/20 plus 12/18 hierarchy;
- rows: wider inset and 52px minimum rhythm;
- empty state: explicit 13/20 measure and padding.

Conversation Markdown, upstream message measure, and QuestionComposer remain
unmodified. The plugin does not use global selectors or DOM monkey patches to
pull those surfaces into this presentation slice.

## Rail geometry

The application rail keeps AppFrame's 56px track and aligns its landmark and
control seats to the vanilla collapsed rail at 36x36px.

Google Material Symbols Rounded paths remain embedded for the three
`dsh-rice` controls. Physical dogfood showed that equal SVG viewport sizes
produced unequal optical ink sizes, so v0 uses:

```text
Big Fat Whale     24px upstream component
Sessions search   22px
New Session       24px
Activity          20px
```

The upstream Settings control remains upstream-owned. Optical compensation
affects only glyph presentation; it does not enlarge the vanilla control-seat
geometry.

See `THIRD_PARTY_NOTICES.md` for the Material Symbols Apache-2.0 attribution.
The Whale is supplied by upstream DSH under the upstream package's existing
provenance and is not redistributed as path data here.

## Commands and input

The v0 command ids are:

- `quickSwitcher`
- `sessionMruNext`
- `sessionMruPrevious`
- `sessionOverview`

No fixed `Ctrl+K`, `Ctrl+Tab`, or `Ctrl+Space` bindings ship.
Browser/OS/IME collision auditing belongs to a later platform keymap layer.
Pointer/touch rail buttons are first-class entry points in v0.

The switcher supports local keyboard navigation: Escape closes,
ArrowUp/ArrowDown move the active row, and Enter opens it. Pointer hover and
row focus also synchronize that active row. Arrow navigation changes are
announced through an overlay-local polite live region; actual current-session
selection is separately exposed through `aria-current`.

`sessionOverview` opens the same transient surface with the Activity lens. A
richer card overview is intentionally deferred.

## Lifecycle

The original `ui-sidebar` row must be disabled. `dsh-rice` declares the same
child seats (`sidebar.workspaces`, `sidebar.settings`,
`sidebar.footer.action`) so existing feature registration lifecycles remain
valid; v0 deliberately does not render the workspace-browser child seat, while
it does render the existing Settings/footer occupants in rail posture.

The rail reads AppFrame's `collapsed` owner prop and uses a layout effect to
toggle only an actually expanded sidebar closed. This makes the v0 56px posture
idempotent across plugin reloads without inventing a second layout state.

A linked checkout may change on disk while a running DSH Web process still
holds older Host/client module state. Current dogfood therefore treats a DSH
process restart after changing plugin heads/build artifacts as the clean
provenance boundary.

## Theme relationship

`dsh-rice` uses ordinary DSH semantic theme variables and does not own palette
production. It works with stock DSH themes.

`dsh-matugen` is an optional, independent semantic theme provider. When both
are composed, `dsh-matugen` updates DSH's semantic `--dsw-*` tokens and
`dsh-rice` repaints its regions, states, and Whale through those same
variables. Neither package imports or configures the other.

## Browser artifact

The generated namespace artifact may require exactly:

```text
react
@deepseek-ai/dsh-client-ui-primitives
```

Both are frozen public DSH Web platform modules at the audited upstream head.
The builder rejects extra imports/requires, dynamic `import(...)`, or residual
ESM syntax.

## Verification boundary

`npm run check` covers repository-local behavior and the generated browser
artifact, including public module requirements, upstream FishLogo reuse,
56px/36px geometry, semantic-only colors, divider removal, state distinctions,
ARIA current/live contracts, and the unchanged Session/Workspace projection.

Physical dogfood with `@deepseek-ai/dsh@0.1.0-rc.6` separately owns real Web
composition evidence: the AppFrame track, Settings/footer survival, full-width
Chat, unaffected Trajectory presentation, optical sizing, and theme repainting.

GitHub Actions runs that fail before any step starts because of account
billing/spending limits are treated as infrastructure failures rather than
code-test evidence.
